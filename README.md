
# SpendWise - Personal Finance Tracker

## Project Description

SpendWise is a personal finance tracking web application
that helps users manage their income, monitor expenses,
and maintain a monthly spending budget.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub
- Netlify

## Features

- Financial dashboard
- Income and expense tracking
- Add and delete transactions
- Expense categorization
- Monthly budget management
- Automatic balance calculation
- Responsive design
- Browser data persistence
